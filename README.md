# Sean Frontend Portfolio

使用 Vue 3 與 Vite 製作的個人前端作品集。

## 開發模式

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本機網址，預設通常是 `http://localhost:5173`。

## 正式建置

```bash
npm run build
```

建置結果會輸出至 `dist` 資料夾。

## 主要內容位置

- `src/data/portfolio.js`：作品、技能與工作經歷資料
- `src/components/`：各頁面區塊元件
- `src/style.css`：網站視覺與響應式排版
